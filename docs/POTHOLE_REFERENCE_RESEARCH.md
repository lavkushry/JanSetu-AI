## What is actually implemented

The shipped detector sends image data URLs to OpenAI's Responses API using `gpt-5-mini`. It returns a pothole verdict, approximate size, self-reported confidence, speed-breaker flag, and description; acceptance uses a 0.5 confidence threshold. It returns no detection boxes. This is hosted vision classification, not an implemented local CNN. [Detector, schema, and image request](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/static/standalone.js#L89).

No training implementation or named checkpoint/ONNX/TFLite artifact appears in the inspected tree. The uninspected ZIP provides no verified model provenance. Android uses a Capacitor wrapper with camera, geolocation, filesystem, and email-composer dependencies. [Source tree](https://api.github.com/repos/Aminem2832/pothole-reporter/git/trees/0c5989f8e0f284dea92f42f8be0de07fcc141868?recursive=1), [Android manifest](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/android-app/package.json).

The UI implements camera/drive capture, bounded concurrent analysis, GPS freshness checks, video retention/reanalysis, and human relabeling. Its settings explicitly disclose photo uploads and third-party location queries. Those disclosures contradict README claims of offline inference and photos/location never leaving the phone. [Capture and disclosure implementation](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/static/index.html#L191), [README claims](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/README.md#L24).

Routing combines municipal boundaries, national-highway exclusion, and a body directory. Rural roads, missing contacts, highways, and failed ownership checks abstain. Recipients are institutional officer titles and emails, not identified engineers for individual roads. Tender matching uses ranked candidates followed by hosted-model selection with a 0.6 threshold. [Routing and matching](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/static/standalone.js#L438).

Complaint text is templated in English/Kannada. Contract matches are described as probable; warranty wording derives from publication age, not verified contract terms. Native email composition opens a draft; a queued record is not proof of sending or official receipt. [Draft and composition](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/static/standalone.js#L735).

## Model and data reliability

The evaluation harness calls the same hosted model; it does not train or distribute weights. Upstream evaluation reports substantial variation between identical-input runs. Labels identify only six owner-confirmed positive photos; negative and disputed labels include unreviewed assistant judgments, and evaluation images are absent. These findings support neither a production accuracy claim nor calibrated confidence or physical size measurements. [Harness](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/eval/run_eval.py#L24), [Reported evaluation](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/eval/README.md), [Label provenance](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/eval/labels.json).

## General official entry point

On 6 October 2026, the [official GBA home page](https://gba.karnataka.gov.in/) and its [currently served application asset](https://gba.karnataka.gov.in/static/js/main.2c80bd9f.js) returned HTTP 200. The asset defines **1533** as the header helpline and the footer toll-free number. This supports a general civic contact entry with `sourceCheckedAt: 2026-10-06`; it does not identify a road owner, responsible engineer, contractor, or accepted complaint. The HTTPS certificate chain and hostname were verified using the site's missing issuer intermediate and system trust roots; TLS verification was retained.

## Reuse and implementation decision

Root `LICENSE` declares MIT with Gaurav Sen's copyright; README prohibits commercial use without permission, and Android package metadata declares ISC. These conflicting declarations do not establish a clear provenance boundary for copying this fork or its bundled data/assets. Proceed through original JanSetu implementations; obtain clear provenance before importing any upstream artifact. The ZIP's contents and safety remain unknown. [License](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/LICENSE), [README license statement](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/README.md#L110), [Package metadata](https://github.com/Aminem2832/pothole-reporter/blob/0c5989f8e0f284dea92f42f8be0de07fcc141868/android-app/package.json).

The following are **JanSetu design proposals**, not upstream capabilities or a completed integration:

- Keep Go/PostgreSQL reporting authoritative. Add a private pothole-analysis adapter over immutable media, with model identity/revision, bounded input, explicit unavailable/uncertain outcomes, and resident review. Existing COCO object detection does not establish pothole capability. Require a separately provisioned, attributable model and a held-out, human-labeled evaluation before claiming local CNN detection.
- Capture selected camera/drive frames with truthful origin and time/location provenance. Keep machine suggestions separate from resident observations; never infer metric dimensions without measurement. An unavailable detector must permit ordinary manual reporting.
- Resolve candidate civic authorities through configured official sources, preserving source URL, source revision, checked-at time, and explicit coverage/failure status. Treat municipality containment as a candidate; verify asset responsibility. Keep institutional contacts separate from personal identity.
- Admit contractor attribution only from a validated official award whose tender reference and award identifiers agree. Until then return an unverified/unavailable contractor state. Do not infer an active warranty from tender publication date.
- Build a structured, editable complaint preview from resident-confirmed details and attributable facts. Preserve private evidence and existing publication consent. Preparing a draft must not send email, claim delivery, open a public post, or substitute for official case acceptance.
